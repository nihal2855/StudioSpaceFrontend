# StudioSpace
    
A modern studio booking platform where users can discover creative spaces, explore studio details, and book studios for their projects.

## Project Overview

StudioSpace is a full-stack web application designed to connect creative professionals with suitable studio spaces. Users can explore different studios, view details, check pricing, and make bookings through an easy-to-use interface.

The platform provides authentication, studio management, booking management, and user dashboards.

## Features

### Authentication
- Email and Password Registration
- Email and Password Login
- Google Authentication
- User Session Management
- Protected Login and Registration Routes
- User Profile Information

### Studio Management
- Browse Available Studios
- Search and Filter Studios
- View Studio Details
- Studio Image Gallery
- Studio Categories
- Studio Pricing and Security Deposit
- Create, Update, and Delete Studios

### Booking System
- Book Available Studios
- Select Booking Date and Time
- View Booking Information
- Manage User Bookings
- Prevent Overlapping Bookings

### User Dashboard
- View Dashboard Overview
- Manage Studio Listings
- View Booking History
- Manage Bookings
- Manage Studio Information

### Additional Features
- Responsive Design
- Loading Skeletons
- Toast Notifications
- Custom 404 Page
- Form Validation
- Light Theme with Orange Accent Color
